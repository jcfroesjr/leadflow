<objective>
Harden the group FSM (`grupo_state.py`) into a strictly monotonic state machine with a mandatory `caller` audit trail. This is the foundation for the whole phase: Plan 02 (LEAVE handler) transitions leads to the new `LEFT_GROUP` state via this API, and Plan 03 migrates all 9 callsites to the new signature.

Purpose: Today `set_grupo_state` has zero transition validation, no `caller`, no audit log. A future bug could silently reset an ATIVO lead to AGUARDANDO and confirmations would go to an empty group. This plan adds the `ALLOWED_TRANSITIONS` guard + per-transition audit marker so every state change is traceable and regressions are structurally impossible without `force=True`.

Output: `grupo_state.py` with `STATE_LEFT_GROUP`, `ALLOWED_TRANSITIONS`, new `set_grupo_state`/`transition_grupo_state` signatures, and `GSC:` audit markers (including BLOCKED).

LOCKED DECISIONS honored:
- D-1: `LEFT_GROUP` is a NEW TERMINAL FSM state (matches SC6), not FALLBACK_1_1.
- D-2: Audit marker prefix is `GSC:` (not `GRUPO_STATE_CHANGE:`) — avoids collision with the existing `.like("GRUPO_STATE:%")` parser in `get_grupo_state`.
</objective>
